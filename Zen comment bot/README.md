# v1 — Dzen AI Comment Bot

Отдельный бот для автоматических ответов на комментарии в Дзен-канале.

## Что делает

1. Авторизуется в Дзен через сохранённую браузерную сессию Playwright.
2. Ищет новые комментарии в Студии; при необходимости использует резервный поиск по последним публикациям.
3. Получает текст комментария и контекст публикации.
4. Передаёт их YandexGPT.
5. YandexGPT принимает решение: `reply`, `skip` или `review`.
6. К нормальному ответу программно добавляется одна из нескольких ненавязчивых фраз со ссылкой на `https://boykovgroup.ru/blog`.
7. В боевом режиме публикует ответ через интерфейс Дзена.
8. SQLite хранит историю и не позволяет повторно отвечать на уже опубликованный комментарий.
9. Управление — отдельный Telegram-бот.

> Важно: автоматизация комментариев реализована через браузерный интерфейс. Верстка Дзена может изменяться. Поэтому все хрупкие CSS/text-селекторы вынесены в `dzen_selectors.py`, а диагностические HTML и скриншоты сохраняются в `data/debug`.

## 1. Подготовка на компьютере

Нужен Python 3.11+.

```bash
python -m venv venv
```

Windows:

```powershell
venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
copy .env.example .env
```

Linux/macOS:

```bash
source venv/bin/activate
pip install -r requirements.txt
playwright install chromium
cp .env.example .env
```

Заполните как минимум:

```env
TELEGRAM_BOT_TOKEN=...
TELEGRAM_ADMIN_ID=...
YANDEX_API_KEY=...
YANDEX_FOLDER_ID=...
```

## 2. Один раз авторизуйте Дзен

На компьютере с графическим интерфейсом:

```bash
python setup_dzen.py
```

Откроется Chromium. Войдите в Яндекс под владельцем нужного канала, откройте Студию и нажмите Enter в терминале. Будет создан:

```text
data/dzen_state.json
```

Этот файл содержит действующую браузерную сессию. Не публикуйте его и не отправляйте посторонним.

## 3. Первый тест без публикации

В `.env` оставьте:

```env
DRY_RUN=true
```

Запустите:

```bash
python diagnose_dzen.py
```

Ожидаемый результат — `AUTH: True` и список найденных комментариев. Если комментарии не нашлись, откройте в Студии раздел комментариев и скопируйте его точный URL в:

```env
DZEN_COMMENTS_URL=https://...
```

После этого:

```bash
python bot.py
```

В Telegram нажмите **«🔎 Проверить сейчас»**. Ответы будут генерироваться и сохраняться в БД, но не публиковаться.

## 4. Запуск на сервере Docker

Перенесите папку проекта на сервер, включая:

```text
.env
data/dzen_state.json
```

Затем:

```bash
docker compose build
docker compose up -d
```

Логи:

```bash
docker logs -f dzen-comment-bot
```

## 5. Включение реальной публикации

Только после успешного DRY_RUN измените:

```env
DRY_RUN=false
```

Перезапустите:

```bash
docker compose up -d --force-recreate
```

Затем в Telegram нажмите **«▶️ Включить»**.

## Telegram-команды

- `/start` — меню
- `/on` — включить автоматическую проверку
- `/off` — остановить автоматическую проверку
- `/check` — проверить комментарии немедленно
- `/status` — состояние, статистика, авторизация
- `/last` — последние 5 обработанных комментариев
- `/auth` — проверить сессию Дзена

## YandexGPT

По умолчанию модель строится так:

```text
gpt://<YANDEX_FOLDER_ID>/yandexgpt/latest
```

Можно явно задать `YANDEX_MODEL`.

OpenAI-compatible endpoint:

```text
https://ai.api.cloud.yandex.net/v1
```

## Защита от нежелательных ответов

YandexGPT возвращает одно из трёх действий:

- `reply` — можно отвечать;
- `skip` — спам/бессмысленный комментарий;
- `review` — неоднозначный или потенциально рискованный вопрос, автоматически не публикуется.

Дополнительно бот:

- не принимает внешнюю ссылку, сгенерированную моделью;
- сам добавляет только заданную ссылку на блог;
- хранит ID/хеш комментария в SQLite;
- в случае ошибки публикации переводит комментарий в `review`;
- делает случайную задержку перед публикацией;
- на старте по умолчанию выключен и работает в `DRY_RUN`.

## Если Дзен изменил интерфейс

Запустите:

```bash
python diagnose_dzen.py
```

При ошибках браузер пишет диагностику в:

```text
data/debug/
```

Основные селекторы находятся только в:

```text
dzen_selectors.py
```

Это позволяет адаптировать бота под новую верстку без изменения YandexGPT, базы, Telegram и общей логики.
