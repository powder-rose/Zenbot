# v59 — ускорение Dzen Comment Responder

Исправлено зависание ручной проверки и недельного запуска.

- Ответы YandexGPT генерируются параллельно (по умолчанию до 3 одновременно).
- Отдельный timeout ответа Responder: 45 секунд вместо общего 180-секундного timeout статьи.
- Telegram показывает прогресс: сканирование → генерация N/M → публикация N/M.
- Если уже идёт фоновая проверка, повторный ручной запуск не висит на lock, а сразу сообщает «Responder уже выполняет другую проверку».
- Добавлены подробные INFO-логи этапов.

Опциональные .env:

DZEN_RESPONDER_REPLY_CONCURRENCY=3
DZEN_RESPONDER_REPLY_TIMEOUT_SECONDS=45
